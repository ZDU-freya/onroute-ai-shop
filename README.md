# AI 高效生活圈

可在本地完整体验的交互业务原型。Next.js 15 + React 19 + TypeScript + Tailwind CSS 4，无数据库、真实地图、AI 或支付服务。全部插画均为项目内 SVG，不依赖外部图片。

## 启动

需要 Node.js 20.9+。首次安装需要网络：

```sh
npm install
npm run dev
```

浏览器打开 http://localhost:3000 。

```sh
npm run check
npm test
npm run build
```

构建结果 `out/` 为可部署到静态托管平台的产物，使用 HTTP 服务访问，勿直接打开文件协议。

## 体验

首页 → AI 地图推荐 → 点击点位/筛选/切换范围 → 查看商家 → 路线预览 → 确认模拟购买 → 核销码 → 返回地图。

- 24 家商家，步行十分钟 8 家、步行二十分钟 18 家、公共交通 24 家。
- SUG 多选按并集；自然语言示例：`30 元以内，想吃面，晚上还营业`。识别后可删除标签或打开筛选面板编辑。无法识别时明确反馈。
- 地图支持点位、空白取消摘要、聚合展开、缩放与视图复位。公共交通显示到店与回家两段路线。地点设置支持三种起点、三种回家地址及未设置测试状态。
- 换一家优先不同品类，支持上一家与反馈重排。只有一家时明确提示并可重置筛选。
- 收藏、今日模拟浏览、订单及广告点击/购买统计存于浏览器 localStorage；在收藏页可增加模拟浏览、查看订单及重置数据。
- 关闭“当前营业”或“可用优惠”筛选可测试打烊与优惠过期状态，此类商家不可购买。
- 路线是预设街网的演示折线；地点变化会更新起点、回家终点和模拟时间，不具备真实导航效力。

## 文件与替换位置

- `data/merchants.ts`：商家、分类、场景映射及预设交通路线数据。
- `lib/recommendation.ts`：纯函数过滤、排序、推荐理由、搜索解析和路线演示计算。后续真实 AI / 商家 / 路线接口在此边界替换。
- `components/CityMap.tsx`：交互 SVG 地图，可替换为地图 SDK。
- `app/page.tsx`：页面视图与会话状态编排，保留地图、筛选与当前选择。
- `public/food-*.svg`：本地套餐示意插画，非实拍。
- `lib/verify.ts`：业务规则自动验证。

原型固定模拟历史行为，没有登录或真实用户数据，所有交易页面均为演示。没有接入任何商业 API。各页面使用 React 视图切换而非独立 URL，刷新后返回首页并保留本地收藏、历史与订单。
