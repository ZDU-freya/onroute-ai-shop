# 抖省省 · AI 顺路买 V3.4（高德真实地图版）

OnRoute AI Shop is an AI-powered local shopping and lifestyle platform that integrates personalized recommendations, real-time map navigation, and commute-based discounts.

在原项目上增量改造。首页、原演示商家、收藏、订单和核销继续保留；AI 页面只保留「AI 顺路买」。地图、POI、位置和交通时间来自高德；优惠、商品、停留和购买为本地原型配置。

## 启动与配置

需要 Node.js 20.9+。本机已安装依赖并配置忽略的 `.env.local`。

```sh
npm install
npm run dev
```

打开 http://localhost:3000 ，进入「AI 顺路买 / AI 地图推荐」。生产运行：`npm run build` 后 `npm run start`。本版本需要 Next.js 服务端安全代理，不能用 Python 静态文件服务器运行；此前 `out/` 和静态压缩包不是本次版本。

其他环境复制 `.env.example` 为 `.env.local`：

- `AMAP_JS_KEY`：高德 Web端(JS API) Key。
- `AMAP_SECURITY_CODE`：同一应用的安全密钥，仅在服务端代理使用。

浏览器按高德 SDK 设计会获得公开 JS Key；安全密钥不进入前端。无需数据库或 AI Key。若控制台设置了域名白名单，需允许本地和部署域名。服务权限、配额与计费以自己的高德账号为准，项目不声明免费额度。线上旧静态版本未自动更新。

## 地图与业务验证

1. 首次进入默认十分钟步行范围。允许定位，或手动搜索城市、出发地，或在地图点选起点。未定位时杭州只是浏览视角，不能冒充实际位置；不默认设置家庭地址。
2. 附近查询每次最多 12 个真实 POI，两个并发进行真实道路时间校验。仅展示完成验证且满足范围的商家，页面明确显示候选半径、校验数量和非全量提示。公交 20 分钟单独调用高德公交方案校验，不能以步行替代。
3. 三张紧凑精选卡复用收藏、今日收藏、浏览与品类兴趣数据；商家不足时不虚构补位。无可靠图片时用标注“非实拍”的中性图。
4. 点击商家或精选卡，自动进入同一张地图的路线聚焦。无终点则要求选择。计算直接通勤和经过主商家的真实分段路线，显示交通、原型停留、完整行程与额外耗时。
5. 根据真实路线几何分段取样搜索沿线 POI，最多验证 4 个候选，逐家计算加入后的真实道路绕路时间。加入后更新路线、到达时间、消费和资格。营业未核实、价格未配置时明确说明。
6. 重置只清除当前临时路线与候选，保留搜索、范围、收藏、已领补贴及订单。序列标识使旧响应无法覆盖新路线；地图实例、图层与事件正确销毁。
7. 不会自动把真实商家变成平台合作商家。默认没有演示合作配置。可在真实商家详情中明确选择“原型验证：配置本机演示优惠”，按高德 POI ID 保存模拟商品、活动截止时间和参与资格；界面标明非真实合作/团购。
8. 通勤档位只根据高德步行时间判定：≤10 分钟 ¥2/30 分钟；>10 至20 分钟 ¥6/60 分钟；>20 分钟 ¥8/120 分钟。参与资格必须另行配置。活动剩余和领取后的核销剩余分开标识，绝对时间戳刷新后不重置。
9. 顺路补为参与配置、加入可行路线的商家提供。¥2–5 金额在同一标签页演示会话中稳定，两类优惠不叠加，购买时择高核实。
10. 商品仍通过原有模拟购买与核销流程完成。真实 POI ID 对应记录会恢复，以支持收藏、订单和补贴继续使用。旧虚拟商家的历史计划保留，但不能在真实地图恢复虚构点位。

不持久化浏览器定位或家庭地址；只有用户勾选“保存为常用地点（仅此设备）”后才在此浏览器保存所选地点。搜索与路线缓存仅在内存使用。

## 文件

- `app/page.tsx`：唯一 AI 入口、真实商家与原有详情/购买/收藏/订单衔接。
- `components/real-map/RealCommute.tsx`：总览/聚焦统一状态、精选、券包、起终点、沿线推荐、演示配置。
- `components/real-map/RealMap.tsx`：真实地图生命周期、点位和高德几何图层；无虚拟地图回退。
- `components/real-map/real-map.css`：隔离的紧凑布局和响应式样式。
- `lib/amap/real.ts`：真实 POI、正反地理编码、有限并发、范围校验、分段路线、POI 与本地业务适配。
- `lib/amap/client.ts`：JS API 2.0 加载与道路路线缓存。复用原有 SDK 加载器，不重复安装第二套加载器。
- `components/nearby/subsidy.ts`、`commute.ts`、`SubsidyPanel.tsx`：兼容明确配置的真实 POI，原演示商家规则不变。
- `data/merchants.ts`：增补可选 POI 与平台优惠字段。
- `app/api/amap/config/route.ts`、`app/%5FAMapService/[...path]/route.ts`：安全配置与固定高德服务白名单代理。
- `public/poi-category.svg`：中性品类示意图。
- 旧逛吃、SVG 地图和规划组件保留底层文件，但 AI 页面不引用它们。

## V3.4 增量：地图沿线标记与券包详情联动

本次不调整三张精选卡、原券包样式、原“顺路买点什么”的 JSX/样式/筛选排序代码，也没有新增独立页面或顶部推荐列表。

- 路线成功后，地图独立查询补充 POI。先沿真实路线取样、按 POI ID 去重并做 450 米空间预筛，再以加入后的高德真实交通时间验证，默认额外交通不超过 10 分钟。阈值在 `lib/amap/supplement.ts` 配置。空间距离不用于冒充交通时间。
- 紫色为顺路商家；橙红火焰为“演示热卖”。演示热卖必须在现有“原型验证：配置本机演示优惠”中明确勾选，并填写演示商品名称；不会给所有 POI 自动贴热卖标签，也不虚构销量或排名。
- 点击补充标记仅高亮并打开地图轻量信息窗。主动“加入路线”才重算。加入失败保留原路线与站点；重置清理临时标记，保留收藏、优惠和订单。
- 原券包的三个按钮现在打开“适用商家”弹层。查询所有已配置参与的 POI，以 `PlaceSearch.getDetails` 核实身份，再按当前起点的实际步行秒数筛选档位；不受附近 12 家候选池限制。无合格数据时明确显示“当前暂无适用商家”。
- 适用商家详情复用原抽屉，补充真实坐标、步行耗时、活动有效期、演示商品名/原价/团购价、领取条件及状态。支持领取、原有模拟购买、地图定位、加入当前路线及返回适用列表。已有路线时追加途经站点；没有路线时设为主商家。
- `productName`、`originalPrice`、`rules`、`hotSale` 为活动配置的可选新增字段，保存在原 `dss-real-offers-v34`，继续使用高德 POI ID 关联。旧配置仍兼容；原价缺失时不虚构划线价。
- 增加 `components/real-map/protected-v34.json`，自动校验受保护的原推荐模块、原推荐管线、三卡 JSX 和原 CSS 与本次修改前一致。
