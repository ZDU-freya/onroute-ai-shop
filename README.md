# 抖省省 · AI 高效生活圈 V3

抖省省风格的非官方业务验证原型。Next.js / React / TypeScript / Tailwind，44 家商家、4 个商圈、5 类主题、13 类任务、5 条预设交通线路及活动预约模拟数据。纯前端，无后端、数据库、真实地图、AI、支付或预约接口。

## 本地启动

需要 Node.js 20.9+：

```sh
npm install
npm run dev
```

打开 http://localhost:3000 。开发服务使用轮询避免 macOS 文件监听数量限制。若执行环境禁止监听端口，需在自己的终端运行。

```sh
npm test
npm run check
npm run build
```

生产静态文件输出至 `out/`，可用任意 HTTP 静态服务器托管。

## 验证流程

- 首页：搜索、品类、价格排序、人气和新店过滤、商品详情均可操作。顶部导航 / 移动端底部导航进入 AI 高效生活圈，默认附近发现。
- 附近发现：场景并集、预算、收藏及营业筛选、点位选择、换一家、缩放、范围切换、单店路线、加入今日计划或逛吃路线。
- 顺路买：添加标签或解析任务文本，设置起终点、交通、出发时间、额外耗时和预算。生成结果展示基准、完整、额外时间及费用。替换商家、改变停留、调整顺序、锁定、删除和执行状态实时重算。必做任务需先手动解除“必须完成”才可删除，已完成任务保持记录。
- 逛吃地图：选择主题、活动标签、商圈、人数、时间、预算和购物支出，生成三站活动。超出时间预算或预约容量时明确标记冲突，采用按钮禁用；可换店、增删站点、修改顺序后重算。
- 站点详情 → 模拟订单 → 成功核销码 → 演示核销 → 返回原计划。
- 保存路线后，在“我的 / 收藏与计划”的“保存计划”中恢复。草稿、收藏、订单、执行状态均通过 localStorage 保存。恢复后根据当前规则重新校验。重置入口在我的页面底部。

## 数据与替换边界

- `data/merchants.ts`：原有 24 家餐饮基础商家。
- `data/planning.ts`：新增 20 家商家、商圈、活动、任务、路线数据及确定性计算规则。
- `lib/recommendation.ts`：附近推荐、过滤、自然语言关键词解析。
- `components/StoreHome.tsx`：抖省省风格首页。
- `components/Planner.tsx`：任务 / 周末路线编辑与计划持久化。
- `components/CityMap.tsx`：可交互 SVG 虚拟地图。
- `app/page.tsx`：模块切换、商家详情、收藏与订单。
- `lib/*verify.ts`：附近与规划规则验证。

商家图片是本地套餐示意插画。路线为明确规则计算的模拟数据，交通耗时包含公交接驳/候车的预设成本，不能用于真实导航。购物支出单独计入人均总预算；未填购物预算为零。预约是模拟时间窗口与容量检查，不占用真实库存。原型使用同商圈候选匹配与确定性排序，不声称全城最优。

界面参考公开抖省省的搜索、品类、优惠及商品流结构，采用红粉强调色进行网页适配，不是逐像素复制或官方接入。
